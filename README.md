### Цель создать игру соответсвующая следующим критериям:
- Использованы классы (наследование, инкапсуляция, полиморфизм)
- Реализовано минимум два класса
- Реализовано 5< механик
- Реализовано 3< концовок игры
- Реализовано взаимодействие между рыцарем и драконом

### Механики

#### Механики плута
- *Пассивный уворот с шансом 50% (Попадание - 2)*
- *специальная атака(Отравление на 3 хода с уроном 10)*
